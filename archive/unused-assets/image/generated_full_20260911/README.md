# 던전 오브 소울 — 생성 이미지 133장

요청 목록의 선택 항목까지 포함한 PNG 원본입니다. 내장 이미지 생성 도구로 제작했습니다.

`index.html`을 브라우저에서 열면 분류별 미리보기와 파일명 검색을 사용할 수 있습니다.

| 분류 | 수량 |
|---|---:|
| 캐릭터 4종 × 방향 3종 × 상태 5종 | 60 |
| 바닥 타일 | 5 |
| 벽 텍스처 | 2 |
| 바닥 장식 | 10 |
| UI 및 타이틀 장식 | 25 |
| 타이틀·로비 배경 | 2 |
| 스킬·장비·펫·다이아 아이콘 | 29 |
| 합계 | 133 |

## 파일과 제작 기록

- 캐릭터: `{class}_{state}_{direction}.png`. class는 warrior/mage/rogue/cleric, direction은 down/side/up, state는 idle/walk/attack/hit/death입니다.
- 요청 프레임 수: idle 4, walk 6, attack 6, hit 3, death 8. side는 오른쪽 방향입니다.
- 나머지 파일은 floor_, wall_, decal_, ui_, background_, icon_ 접두사로 구분했습니다.
- 제작 프롬프트와 생성 원본 위치: 각 `*prompts.json` 파일.
- 실제 이미지 크기와 투명도 표본: `asset_dimensions.json`.
- 캐릭터 원본 위치: `player_manifest.json`.

## 적용 상태

이 폴더에는 생성 도구가 출력한 원본을 보존했습니다. 요청서의 프레임 셀 240×320 및 아이콘 128×128로 정규화한 파일은 아닙니다. 이미지별 실제 크기는 목록에 기록되어 있습니다.

캐릭터 시트는 게임에 적용하기 전에 프레임 간격·발 기준선·공격 이펙트의 셀 경계를 확인하고 정렬해야 합니다. 타일 반복 경계와 UI 상태별 외곽 형태 일치도 실제 화면에서 확인해야 합니다. 게임 코드 연결은 진행하지 않았습니다.

PNG 133개를 모두 열어 읽을 수 있는지 확인했고, 캐릭터 및 아이콘 모서리의 투명도와 카드·모달 중앙의 투명도를 표본 확인했습니다. 이 표본 검사는 이미지 전체 픽셀의 배경 정리나 애니메이션 동작 검증을 의미하지 않습니다.
