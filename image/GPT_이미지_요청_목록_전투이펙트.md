# 던전 오브 소울 — 전투 이펙트(VFX) GPT 이미지 요청 목록

현재 상태 확인 결과: 기본공격/Q/W/E/R 스킬의 시각 효과가 **전부 캔버스로 그린 단색 도형**입니다
(흰 부채꼴, 색깔 원, 링 등 — `game.js`의 `meleeArcAttack/fireProjectiles/spawnRing` 등).
실제 이펙트 이미지는 하나도 없습니다. 아래는 그걸 교체할 이미지 목록입니다.

## 0. 공통 스타일 지침

- **화풍을 반드시 캐릭터 스프라이트(`image/player_anim/*.png`, `image/*_walk_strip_256.png`)와 맞출 것** — 지금 캐릭터는 도트(픽셀아트) 느낌이 살아있는 스타일입니다. 매끈한 유화풍으로 만들면 캐릭터랑 따로 놀아 보입니다. 레퍼런스로 기존 캐릭터/몬스터 이미지를 같이 첨부하세요.
- 배경 투명 PNG. 정사각형 캔버스 권장(발사체/폭발류), 가로로 긴 캔버스는 "베기" 계열에만.
- 기본 방향은 **오른쪽(→)을 향하게** 그려주세요 — 코드에서 실제 이동/공격 방향으로 회전시켜 씁니다.
- 색상은 속성별로 통일: 물리 베기=흰색/은색, 화염=주황~빨강, 냉기=하늘색~시안, 마력/비전=보라~파랑, 신성=금색~흰색, 대지=갈색, 번개=노랑~흰색.
- 형식: 대부분 **정지 이미지 1장**이면 충분합니다(코드에서 크기/회전/투명도를 애니메이션시킴). 아래 표에서 "프레임"이 표시된 항목만 여러 장(짧은 재생용)이 필요합니다.

## 1. 기본공격 (항상 보이는 것 — 최우선)

| 클래스 | 유형 | 필요 이미지 | 비고 |
|---|---|---|---|
| 대검사(warrior) | 근접 부채꼴 베기 | **검격 스와시(swoosh) 1장** — 넓은 부채꼴 궤적의 흰색/은색 검기 잔상 | 지금은 흰 반투명 부채꼴 도형뿐 |
| 마법사(mage) | 원거리 발사체 | **마력탄(arcane bolt) 1장** (작고 둥근 보라/파랑 에너지 구슬, 살짝 빛나는 느낌) | 날아가는 동안 이 이미지가 이동 |
| 도적(rogue) | 근접 찌르기 | **단검 찌르기 스파크 1장** (짧고 날카로운 흰색 섬광선) | |
| 성기사(cleric) | 광역 파동 | **성스러운 파동 링 1장** (금색/흰색 원형 충격파 — 중심에서 퍼지는 반투명 원) | 지금은 색깔 원 하나뿐 |

| 서리 지팡이 | 냉기 폭발 | **냉기 폭발 1장** (파랗게 퍼지는 얼음 파편/서리 폭발) + 가능하면 **감속 장판 1장**(바닥에 남는 서리) |

| 스킬 | 필요 이미지 |
|---|---|
| 낙뢰 강타 | **번개 낙뢰 1장** (하늘에서 내리치는 노란빛 번개 기둥, 세로로 긴 캔버스) + 가능하면 **착탄 스파크 4프레임** |

## 요약 — 최소 vs 전체

- **최소로 시작한다면**: 1번 표(기본공격 4장) + 2번 표의 파이어볼 세트(3장) + 5번 낙뢰(1장) = **8장 정도**로도 체감이 크게 달라집니다.
- **전체 다 받으면**: 정지 이미지 약 18장 + 4프레임 버스트 애니메이션 3세트(파이어볼 폭발/메테오 착탄/낙뢰 스파크, 각 4장 = 12장) = **총 30장 안팎**.

받으시면 `image/vfx/`에 넣고 알려주세요 — `game.js`의 `meleeArcAttack/fireProjectiles/qMageFireball/spawnRing` 등 절차적 렌더링 부분을 이미지 기반으로 교체하겠습니다.
