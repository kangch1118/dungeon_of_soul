내장 이미지 생성 도구로 제작한 PNG 원본입니다. 요청서의 선택 항목도 포함했습니다.

- 정지 이미지 22장: 기본공격 4종, Q 전용 4종, 무기·패시브 7종, 전직 5종, 낙뢰 1종, 조작법 키캡 1종.
- 파이어볼 폭발: q_fire_explosion_01.png ~ 04.png.
- 메테오 착탄: e_meteor_explosion_01.png ~ 04.png.
- 낙뢰 착탄: r_lightning_spark_01.png ~ 04.png.
- 화염 장판: q_fire_ground_01.png ~ 03.png.

## 보기와 적용

index.html을 브라우저에서 열면 전체 파일과 4개 애니메이션 세트의 순차 재생을 볼 수 있습니다. 재생 속도는 검토용 예시입니다.

발사체·검기는 오른쪽이 기본 방향입니다. e_arrow_fall과 r_lightning_bolt는 아래 방향입니다. 원형 충격파와 장판은 중심 기준입니다. q_shuriken은 회전용으로 중앙에 배치했습니다. ui_control_keycap은 글자 없이 제작했습니다.

번호가 붙은 15개 애니메이션 프레임은 모두 1254×1254입니다. 나머지는 asset_dimensions.json에 실제 크기가 기록되어 있습니다. 실제 게임 표시 크기, 회전 중심, 재생 시간, 투명도는 게임 적용 단계에서 맞춰야 합니다. 게임 코드에는 아직 연결하지 않았습니다.

## 검증 및 기록

PNG 37개를 모두 열어 읽었고 요청 파일명의 누락이 없음을 확인했습니다. 모든 파일의 좌상단 픽셀 알파가 0임을 확인했습니다. 이 검사는 전체 이미지의 모든 픽셀에 대한 투명도 검증은 아닙니다. 생성 결과를 보며 물리 검격 색상, 표창 중심 배치, 화염 장판 원형 형태를 보정했습니다.

최종 선택본의 프롬프트와 생성 원본 경로는 final_prompts.json입니다. static_prompts.json과 animation_prompts.json은 초기 제작 기록이며 일부 보정 전 이미지 경로가 포함됩니다. 사용 파일은 이 폴더의 PNG 및 final_prompts.json을 기준으로 합니다.
