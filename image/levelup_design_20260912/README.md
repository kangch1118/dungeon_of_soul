## 사용

- index.html은 독립 미리보기입니다. 카드에 마우스를 올리거나 키보드로 선택하고 클릭하면 섬광을 볼 수 있습니다.
- 이름·설명·수치는 이미지에 포함하지 않았습니다. 게임의 SKILL_POOL 데이터를 그대로 연결하세요.
- 카드 배경은 전체 이미지이므로 2:3 비율을 유지합니다. 9-slice 테두리로 바로 사용하지 마세요.
- 아이콘은 약 64~115px 표시 권장. 원본은 고해상도이므로 실제 배포 전 표시 크기에 맞는 축소본을 준비하세요.
- 후광은 낮은 불투명도로 아이콘 뒤에 사용합니다. 섬광은 약 0.5~0.7초 확대·페이드하면 됩니다. PNG 자체는 정지 이미지이며 미리보기의 움직임은 CSS로 구현했습니다.
- 카드 금색은 디자인 테마입니다. 현재 레벨업 카드에 없는 등급·능력 차이를 의미하지 않습니다.
- 원본 생성 프롬프트와 출처는 prompts.json에 기록합니다.

현재 레벨업 카드의 나머지 아이콘(질주·관통·다중 사격·치명타·재생 등)은 이번 6종 제작 범위에 포함되지 않았습니다.
