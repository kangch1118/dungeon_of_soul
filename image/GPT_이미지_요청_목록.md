# 던전 오브 소울 — GPT 이미지 제작 요청 목록

작성 기준: `game.js`(모션/렌더링), `data.js`(직업·아이템·펫·몬스터 정의), `style.css`(현재 UI 톤),
`image/classmoving.png`(클래스 모션 레퍼런스), `image/portrait|player/*.png`(기존 클래스 아트),
`UI GUI vs Graphics Expertise/`(UI 참고용 React 목업) 확인 후 작성.

결정된 방향: **① 4방향 모션 개별 제작, ② 스테이지별 풀 배경, ③ 패널·버튼까지 텍스처화**

---

## 0. 모든 요청에 공통으로 붙일 스타일 지침

GPT에 이미지를 요청할 때마다 아래를 프롬프트 앞부분에 고정으로 붙이세요(레퍼런스 이미지도 같이 첨부 권장: `classmoving.png`, `image/portrait/*.png`, `image/*_walk_strip_256.png`, `image/boss/vampire_2.png`).

- 장르: 탑다운 로그라이크 액션 RPG "던전 오브 소울". 다크판타지 톤, 채도 낮은 배경 + 마법/금속 하이라이트 발광.
- 캐릭터/아이템/아이콘류는 **반드시 배경 투명 PNG**.
- 이미 만든 몬스터(`image/*_strip_256.png`)·보스(`image/boss/vampire_*.png`)·클래스 초상화(`image/portrait/*.png`)와 화풍(선 두께, 채색 방식, 명암)이 어긋나지 않게 통일 요청.
- 스프라이트 시트는 프레임을 **가로로 균등 간격 배치**, 각 프레임 폭 동일, 캐릭터의 "발 위치(바닥 접지선)"가 모든 프레임에서 같은 y좌표에 오도록 명시(안 그러면 애니메이션이 위아래로 떨림).

## 1. 플레이어 캐릭터 모션 스프라이트 — 최우선

대상 4클래스: **대검사(warrior) / 마법사(mage) / 도적(rogue) / 성기사(cleric)**

### 방향은 3세트만 요청 (down/side/up) — 왼쪽은 좌우반전으로 처리
`game.js`에 이미 `ANIM_DIR_COL = { down, side, up }` 구조가 있고, `classmoving.png` 원본도 좌/우가 서로 거울상입니다.
→ **정면(down) / 측면-오른쪽(side) / 후면(up)** 3방향만 그리게 하고, 왼쪽 이동은 엔진에서 `scale(-1,1)`로 반전 처리(이미 쓰던 방식) → 요청 수량 25% 절감.
(정말 좌우 비대칭 무기/방패 연출을 원하면 좌우 별도 요청도 가능하다고 말씀 주세요.)

### 상태별 프레임 수 (classmoving.png의 "공통 권장 프레임 수" 그대로)

| 상태 | 프레임 수 | 비고 |
|---|---|---|
| 대기(idle) | 4 | 숨쉬기 정도의 미세 모션 |
| 걷기(walk) | 6 | 발걸음 루프 |
| 공격(attack) | 6 | 준비→타격→회수 |
| 피격(hit) | 3 | 움찔 + 넉백 리액션 |
| *(선택) 사망(death)* | 8 | 필수 아님, 나중에 추가 가능 |

### 필요 이미지 수
4클래스 × 3방향 × 4상태(idle/walk/attack/hit) = **48장** (death까지 포함 시 +12장 = 60장)

### 시트 스펙
- 프레임 셀 크기: **240×320px** 권장(정사각형 아님 — 인체 비율이라 세로가 더 필요). 클래스 간 동일 크기 통일.
- 배경 투명, 캐릭터는 셀 중앙 정렬, 발끝은 셀 하단에서 약 10~15px 위(그림자 공간 확보).
- 무기/장비 실루엣이 클래스 초상화(`image/portrait/{class}.png`)와 일치해야 함(예: 대검사=거대한 검, 마법사=지팡이, 도적=쌍검/단검, 성기사=검+방패).
- 공격 모션 타입 참고(같은 상태여도 클래스별 동작이 달라야 자연스러움):
  - 대검사: 크게 휘두르는 베기(현재 `data.js` 근접 부채꼴 공격)
  - 마법사: 지팡이를 앞으로 뻗으며 마력탄 발사 포즈
  - 도적: 빠른 연속 찌르기(사거리 짧음)
  - 성기사: 주변으로 퍼지는 성스러운 파동을 내뿜는 포즈(광역기)

### 파일명 제안 (엔진에 넣을 때 그대로 매핑)
`image/player/{class}_{idle|walk|attack|hit}_{down|side|up}.png`
예: `image/player/warrior_walk_side.png`

## 2. 스테이지 배경 — 시임리스 타일 방식 권장

`game.js` 확인 결과 맵은 **2600×2600px 고정 크기 아레나**이고 카메라가 그 안에서 스크롤합니다(무한 맵 아님).
GPT 이미지 해상도로 2600px 전체를 한 장의 유니크한 그림으로 그리는 건 비효율적이라, **스테이지별 "시임리스 반복 타일"** 을 요청해서 지금의 절차적 돌바닥 렌더링을 이미지 타일로 교체하는 걸 권장합니다(선택하신 "풀 배경 아트"는 이 타일들로 화면을 가득 채우는 방식으로 구현).

`data.js`의 `stageMonsterPool()` 기준 바이옴 매핑:

| 스테이지 | 등장 몬스터 | 추천 바이옴 |
|---|---|---|
| 1 | 슬라임 | 축축한 던전 입구 / 이끼 낀 석재 바닥 |
| 2 | 슬라임+박쥐 | 어두운 박쥐 동굴 |
| 3 | 박쥐+고블린 | 고블린 소굴(나무 잔해, 흙바닥) |
| 4 | 고블린+스켈레톤 | 지하 묘지(뼈, 관) |
| 5 | 고블린+스켈레톤+박쥐 | 부패한 왕도(기존 배경 유지) |
| 6 | 고블린+스켈레톤+박쥐 | 왕도 초입(기존 배경 유지) |
| 7 | 고블린+스켈레톤+박쥐 | 성내(기존 배경 유지) |

지역 이름만 변경한 상태이며, 배경 이미지·보스·등장 몬스터·스테이지 진행 규칙은 기존 설정을 유지한다. 8스테이지 이후 지역 이름은 미정이다.

### 필요 이미지
- **바닥 시임리스 타일 × 5장** (위 표 기준), 512×512 또는 1024×1024, 정타원 없는 완전 수직 탑다운 시점(원근 없음 — 기존 절차적 타일과 동일한 시점), 이음매 없이 반복되도록 명시(`seamless tileable texture` 라고 프롬프트에 꼭 넣기).
- **벽/경계 텍스처 × 1~2장** (공용 어두운 석벽 하나로 통일해도 충분, 원하면 스테이지별로 분리 가능)
- *(선택)* **바닥 장식 스티커 × 6~10장** — 잔해, 뼈, 촛불, 균열, 이끼 등 투명 PNG 낱개 이미지. 코드에서 타일 위에 랜덤 배치하면 매번 같은 반복 패턴처럼 안 보여서 "풀 배경 아트" 느낌이 훨씬 살아남.

## 3. UI 패널·버튼 텍스처

현재 실제 게임(`style.css`)은 **네이비(`#17223c → #0d1526`) + 골드(`#d9a441` / `#f5d891`) 그라디언트 + 팔각형 모서리컷(clip-path)** 을 CSS만으로 그리고 있습니다(이미지 없음). 이 톤을 유지하면서 아래 요소들을 텍스처 이미지로 교체 요청하세요. **(주의: `UI GUI vs Graphics Expertise` 폴더는 갈색 양피지풍 React 시안이라 실제 게임 톤과 다릅니다 — 참고용이 아니라 헷갈리지 않게 네이비+골드 톤 기준으로 요청하세요.)**

| 요소 | 설명 | 참고 |
|---|---|---|
| 패널 배경 | 팔각 모서리컷 네이비 금속판, 중앙은 무늬 절제, 가장자리에 금색 세선 장식 | HUD/로비/모달 공용 |
| 버튼(기본/호버/눌림) | 팔각컷, 금색 테두리, 눌림은 어둡게 | `.menu-btn`, `.img-btn` |
| HUD 바 프레임 | 우측이 뾰족한 셰브론 모양 금속 테두리(안쪽은 투명 — 채워지는 바는 코드에서 그림) | HP/실드/EXP/보스 바 |
| 핫바 슬롯(Q/W/E/R) | 육각 톱니 모양(`clip-path` 참고) 금속 테두리 | 스킬 슬롯 4칸 |
| 코너 버튼(일시정지) | 원형 금속 프레임 | `.corner-btn` |
| 가상 조이스틱 | 베이스(도넛형 금속 링) + 노브(둥근 보석/금속 손잡이) | 터치 전용 |
| 모달 프레임 | 레벨업/스테이지클리어/게임오버/일시정지/전직/뽑기 공용 큰 창틀 | |
| 탭 버튼 | 캐릭터/장비/게임/상점/펫 5개 탭, 활성/비활성 상태 | |
| 카드 프레임 | 스킬카드/아이템카드/상점카드 공용, **등급별 테두리색**(일반 `#b9c4d6`/희귀 `#5fb0ff`/영웅 `#c46bff`/전설 `#ffcf5c`) 반영 | |
| 타이틀 로고 엠블럼 | "던전 오브 소울" 제목 배경 장식(문장/리본) | 타이틀 화면 |
| *(선택)* 타이틀·로비 배경 그림 | 현재 `background.jpeg`가 화풍이 다를 수 있어 새 화풍으로 재제작 고려 | |

각 텍스처는 CSS `clip-path`와 같이 쓸 거라 **모서리를 이미지 자체에서 잘라내지 말고 사각형 캔버스 안에 팔각/육각 장식만 그려서** 주는 게 안전합니다(자르는 건 코드가 함). 9-slice로 늘려 쓸 걸 감안해 **중앙부는 단순한 패턴**으로 요청하세요.

## 요약 — 우선순위

1. **플레이어 모션 스프라이트 48장** (요청하신 "무빙" 구현의 핵심, 이게 없으면 애니메이션 코드 작업을 시작 못함)
2. **스테이지 바닥 타일 5장 + 벽 텍스처 1~2장** (+선택 장식 스티커)
3. **UI 패널/버튼/바/카드 텍스처 세트** (10여 종)
4. *(선택)* 아이콘 세트

1번(캐릭터 모션)부터 받아오시면 바로 `game.js` 애니메이션 로직(프레임 슬라이싱, `player.animState`/`animDir`/`animFrame` 처리)을 몬스터 스프라이트 패턴과 동일하게 구현할 수 있습니다.
